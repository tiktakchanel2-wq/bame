# Bame (Fabric, клиентский мод) — Minecraft 1.21 – 1.21.11

После убийства игрока из вашего списка мод сам пишет в чат заданное сообщение.

* Меню: команда `/bame` — добавить ник, изменить сообщение, вкл/выкл, удалить.
* В сообщении можно использовать `{player}` — подставится ник убитого. Если сообщение начинается с `/`, оно отправится как команда.
* Данные: `.minecraft/config/bame.json`.

## Установка
1. Fabric Loader + **Fabric API** (скачать на Modrinth, положить в `mods`).
2. `bame-1.0.0.jar` в `mods`.

## Сборка
JDK 21 + Gradle 8.12+ :  `gradle build` → `build/libs/bame-1.0.0.jar`
(либо залить папку на GitHub — Actions соберёт jar сам, см. `.github/workflows/build.yml`).
